# CSS Grid Exercises

A collection of **12 exercises and designs** created to practice and improve CSS Grid skills.

## Technologies

* HTML5
* CSS3
* CSS Grid

## About

Each exercise focuses on different CSS Grid concepts such as:

* Grid columns and rows
* Gaps and spacing
* Grid areas
* Element positioning
* Responsive layouts

## How to Run

Open any exercise's `index.html` file in your browser.
